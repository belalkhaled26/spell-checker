# spell-checker
you can now check the spelling of every word you write with this program and it will tell you the successor and predecessor in an AVL tree to help you find your correct word
HOW TO COMPILE:copy this in your terminal
gcc spellchecker.c -o spellchecker -L. -lraylib -lwinmm -lgdi32 -lopengl32 -lm
make sure you have a file containing spellcheck.c raylib.h libraylib.a dictionary.txt
